# 똑딜 🛒

직접 골라 담은 생활·먹거리 특가를 모아 두는 핫딜 모음 사이트, '똑딜'입니다.
GitHub Pages로 https://flyhigh713-hue.github.io/ 에서 열립니다.

- `index.html` — 사이트 전체 (디자인 + 화면 로직, 단일 파일)
- `deals.json` — 핫딜 데이터 (여기만 고치면 사이트에 바로 반영)

## 핫딜 추가하는 법

`deals.json`의 `deals` 배열에 객체를 하나 추가하고 `main` 브랜치에 push하면
1~2분 안에 사이트에 반영됩니다. 새 핫딜이 위로 오도록 **날짜 기준 최신순**으로 자동 정렬됩니다.

```json
{
  "siteTitle": "똑딜",
  "openChatUrl": "",
  "openChatLabel": "실시간 핫딜 오픈채팅방 입장하기",
  "deals": [
    {
      "id": "2026-11-26-vitamin-c",
      "title": "고려은단 비타민C 1000 180정",
      "category": "영양제",
      "partner": "쿠팡",
      "price": 12900,
      "originalPrice": 22000,
      "url": "https://link.coupang.com/a/...",
      "hook": "가족이랑 나눠 먹기 좋은 기본 비타민. 한 통이면 두 달 넘게 갑니다.",
      "dateAdded": "2026-11-26",
      "image": ""
    }
  ]
}
```

### 필드 정리

| 필드 | 필수 | 설명 |
| --- | --- | --- |
| `title` | ✅ | 상품명. 카드 제목으로 크게 나옵니다. |
| `category` | ✅ | `영양제` / `생활템` / `뷰티` / `기타` 중 하나. 목록에 없는 값을 쓰면 필터 칩이 자동으로 늘어납니다. |
| `partner` | ✅ | `토스쇼핑` 또는 `쿠팡`. 카드 좌상단 배지로 표시됩니다. (하단 공시 문구에는 정식 제휴명인 `토스 쉐어링크` / `쿠팡 파트너스`가 자동으로 들어갑니다.) |
| `url` | ✅ | 실제 제휴(어필리에이트) 링크. 비어 있으면 버튼이 "준비 중" 상태로 보입니다. |
| `price` | | 숫자(12900) 또는 문자열("12,900원"). 할인가입니다. |
| `originalPrice` | | 정가. `price`보다 크면 할인율(%)과 취소선 가격이 자동 계산됩니다. |
| `hook` | | 1~2줄 소감·한줄평. 두 줄까지만 보이고 넘치면 말줄임 처리됩니다. |
| `dateAdded` | | `YYYY-MM-DD`. 정렬과 "오늘 / 어제 / N일 전" 표시에 쓰입니다. |
| `image` | | 상품 이미지 URL. 비우면 카테고리 이모지 자리표시자가 나옵니다. |
| `id` | | 관리용 식별자. 없어도 동작합니다. |

### 지켜야 할 것

- **가짜 가격·가짜 링크는 넣지 않습니다.** 실제로 확인한 가격과 실제 제휴 링크만 올립니다.
- 가격·재고는 올린 시점 기준이라 바뀔 수 있다는 안내가 푸터에 들어 있습니다.
- 카드마다, 그리고 푸터에 제휴 고지 문구가 자동으로 들어갑니다:
  > 이 포스팅은 토스 쉐어링크 / 쿠팡 파트너스 활동의 일환으로 이에 따른 일정액의 수수료를 제공받습니다.

## 오픈채팅방 연결

`deals.json`의 `openChatUrl`에 오픈채팅방 링크를 넣으면
목록 위에 안내 배너가 자동으로 나타나고, 빈 목록 화면에도 입장 버튼이 생깁니다.
비워 두면 배너는 보이지 않습니다.

## 참고

- 데이터는 `deals.json?v=타임스탬프`로 `no-store` 요청해서 항상 최신 내용을 읽습니다.
- `deals`가 비어 있으면 "곧 오늘의 첫 핫딜이 올라옵니다! ✨" 빈 화면이 나옵니다.
